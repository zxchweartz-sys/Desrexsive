## Сборка

Проект готов к работе в IntelliJ IDEA.

```
./gradlew build
```

Готовый мод появится в `build/libs/`.

## RU

Полностью очищенный код от мусора, ненужного кода, импортов, аннотаций и т.д.

Многие переменные — это буквы алфавита, но правильно их переименовывать очень муторно и долго.

Примем любые пулл реквесты, не стесняйтесь!

Билд проверен на двух Linux машинах.

### EN

A clean client, stripped of shit, unnecessary code, imports, annotations, etc.

Many variables are just letters of the alphabet, but renaming them properly is very tedious and time-consuming.

We'll accept any pull requests, feel free to submit them!

Build checked on two Linux machines.
